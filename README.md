# React Todo List App

A responsive Todo List application built using React, JavaScript, and CSS.

## Features

- Add new tasks
- Delete tasks
- Mark individual tasks as completed
- Mark all tasks as completed
- Automatic task numbering
- Input clears after adding a task
- Dark theme with responsive styling

## Technologies Used

- React
- JavaScript
- CSS
- Vite
- UUID

## Getting Started

**1. Install dependencies**

```bash
npm install
```

**2. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## Concepts Learned

- React functional components
- `useState` for state management
- Event handling
- Rendering lists using `map()`
- Array methods: `map()` and `filter()`
- Conditional rendering and styling
- Generating unique IDs with UUID
